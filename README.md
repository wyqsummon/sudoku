# 数独 Sudoku

自制的跨平台数独游戏：**一套 .NET MAUI (C#) 代码，同时产出 Windows EXE 与 Android APK**。

- 出题保证**唯一解**，难度按**人类解题技巧**判定（不是简单看已知数个数）
- 深浅双主题、候选数（笔记）模式、撤销/重做、自动存档、最简提示
- 为「阶段二·技法实验室」预留了技法引擎与棋盘绘制层（强弱链画线、分段式提示）

## 二、阶段一功能

**开局与出题**
- 难度分级：简单 / 中等 / 困难，**唯一解**出题，中心对称挖洞（题面美观）
- **一键自动标记候选数**，设置里可开「新局自动标记」
- 一键清除候选数、单格候选数编辑

**输入与联动**
- 数字面板（1–9）、橡皮擦、笔记模式切换
- Windows 物理键盘：`1-9` 填数、`Backspace/Delete/0` 清除、方向键移动、`N` 笔记、`Z/Y` 撤销/重做、`H` 提示、`P` 暂停
- 落子后自动清理同行/列/宫的该候选数（可关闭）
- 撤销/重做覆盖落子与笔记，含批量操作（如自动标记）

**高亮与规则**
- 同类数字高亮、相关行/列/宫高亮、冲突（重复）红色高亮（均可关闭）
- 错误次数上限可配置：不限 / 3 次 / 5 次

**进度与存档**
- 计时器、剩余空格计数、胜利动画
- 每步自动存档（含候选数、计时、错误数、提示数），可从主菜单「继续上一局」
- 卡片式结果浮层：用时 / 错误 / 提示统计

**外观**
- 深浅双主题，跟随系统或手动指定

## 三、难度是如何判定的

`Sudoku.Core` 内置一个**人类技巧求解器**（不做试数），按技巧难度递增推导：

| 等级 | 判定 |
|---|---|
| 简单 | 只用「唯一候选数 / 隐藏唯一候选数」即可完成 |
| 中等 | 需要「区块摒除 / 显性数对 / 隐性数对」 |
| 困难 | 需要「三数组」或更高级技巧（链级技巧留待阶段二） |

出题流程：生成完整终盘 → 在保证唯一解的前提下对称挖洞 → 用技巧求解器评级 → 若偏难则回填线索校准到目标档位。

## 五、开发环境

项目**不依赖系统级 .NET 安装**，工具链放在仓库内的 `.toolchain/`：

```powershell
# 首次（其他机器上复现时）：安装项目内 .NET 10 SDK + MAUI workload
pwsh -File scripts\install-toolchain.ps1

# 每次开发前：启用项目内 SDK
. .\scripts\dev-env.ps1
```

要求：Windows 10 1809+；Android 端需 Android SDK（见下）。

### Windows 版怎么用

`scripts\publish-windows.ps1` 会在 `publish\windows\` 生成 **绿色版**（自包含 .NET 与 Windows App SDK，
目标机器无需预装任何运行时）：双击其中的 `Sudoku.exe` 即可运行，整个目录可拷贝到任意 Windows 10/11 x64 机器。
如需压缩包，加 `-Zip` 参数即可生成 `publish\Sudoku-win-x64.zip`。

### Android 版签名

APK 使用 `keystore\sudoku.keystore` 签名（自签名，仅供自用侧载）：

| 项 | 值 |
|---|---|
| 密钥库 | `keystore\sudoku.keystore` |
| 别名 alias | `sudoku` |
| 库口令 / 密钥口令 | `sudoku2026` |
| 有效期 | 10000 天 |

> ⚠️ 升级安装新版本必须用**同一个密钥库**签名，否则手机会拒绝覆盖安装。
> 请妥善保存该文件（已在 `.gitignore` 中，不会入库）；密钥库丢了就只能卸载重装。

## 七、阶段二 · 技法实验室（开发中）

计划拆成五块，逐块实现并配单元测试：

| 子项 | 内容 | 状态 |
|---|---|---|
| 2.1 技法引擎扩展 | 技法扩展到链级：X-Wing、Swordfish、XY-Wing、X-Chain、XY-Chain；每步附带中文推导说明与链路数据（强/弱链） | 🚧 X 翼 / 剑鱼 / XY 翼已完成（含测试与求解器接入）；X 链 / XY 链 / AIC 进行中 |
| 2.2 分段式提示 | 开启后：① 列出当前可用技巧及数量 → ② 用户选择技巧，多实例时选择路径 → ③ 逐步推进展示推导与候选数删除；关闭时退化为 Hodoku 式一键单步求解 | ⏳ |
| 2.3 强弱链画线 | 格内候选数 → 另一格候选数自由画线，实线=强链、虚线=弱链，可撤销、随存档保存、可整体显隐 | ⏳ |
| 2.4 难度评分 | 基于所用技巧的 SER 风格星级评分，并新增「专家」档（需要链级技巧） | ⏳ |
| 2.5 盘面导入导出 | SDK 文本格式（兼容 Hodoku 谜题）导入与导出 | ⏳ |

设计要点：

- 提示与画线共用同一套「链路」数据结构：技法引擎推导出的强/弱链可直接高亮在棋盘上，用户手绘的链与之互不干扰（纯自由画线，不做正确性校验）
- 提示文案不依赖独立技法百科，推导说明就地展示在提示面板中

> 参考实现思路来自 Hodoku（Java 开源解谜教学器）。Hodoku 为 GPL-3，本项目**只参考其行为与术语，代码全部自行实现**，不引入 GPL 代码。
